CONTACT MANAGEMENT APP - JAVA

PROJECT TYPE:
Console-based Java Contact Management Application

ECLIPSE SETUP:
1. Open Eclipse.
2. Select File > New > Java Project.
3. Name the project: ContactManagementApp
4. Inside src, create:
   - Contact.java
   - ContactManager.java
   - ContactManagementApp.java
5. Paste the corresponding code into each class.
6. Run ContactManagementApp.java as Java Application.

FEATURES:
- Add contact
- View all contacts
- Search contact by ID
- Search contact by name
- Update contact
- Delete contact
- Delete confirmation
- Phone number validation
- Email validation
- Duplicate ID prevention
- Clean OOP structure

OOP STRUCTURE:
Contact.java
- Represents a contact object.
- Stores ID, name, phone and email.

ContactManager.java
- Handles contact collection and CRUD operations.
- Provides search functionality.

ContactManagementApp.java
- Handles menu and user interaction.
- Validates input.
- Calls ContactManager methods.

CONCEPTS USED:
- Classes and objects
- Encapsulation
- ArrayList / List
- Methods
- CRUD operations
- Searching
- Exception handling
- Regular expressions
- Input validation
